Token Launch Radar · model catfit-2 · snapshot of …

Protocols that record no token yet, priced as if they launched today.

Every protocol in the sealed DefiLlama snapshot that records no token is ranked by an implied value: what its token would be worth if it issued one at the multiple its own category already trades at. Protocols whose token already trades are never ranked — they are the evidence, shown apart under Already trading. The snapshot is DefiLlama’s record: a protocol here records no token, which is not proof it has none.

How each implied value is derived

The model is fitted from the snapshot itself, at run time, on the … protocols whose token already trades. For each category it takes the median market-cap-to-TVL ratio of that category’s traded protocols, shrunk toward the global median (…) by sample size — a thin category borrows from the whole market, a deep one stands on its own — and clamps the result between 0.02 and 3.0. Then, for a pre-token protocol:

implied value = TVL × category multiple × growth factor × maturity factor

The growth factor is 1 + the 7-day TVL change, clamped to −30%…+50%, times 0.6 (so a hot week is worth up to ×1.30, a bad one as little as ×0.82). The maturity factor rises from 0.75 to 1.25 across a protocol’s first four years running with no token: the longer it has operated tokenless, the more of its record a launch would price in. No protocol’s name is special-cased anywhere: one fitted function scores every row, and each row’s detail view shows its own arithmetic. Wrapped, staked and bridged products of tokens that already trade (a wrapped-BTC bridge is Bitcoin in transit, not a launch waiting to happen) and exchanges are left off the board at every size, for the same reason the watchlist leaves them out: … such products sit in this snapshot, several of them larger than everything on the board.

Already trading — the evidence, not the board

These protocols’ tokens already trade, so the radar does not rank them: it shows the market’s own market cap beside the TVL the model’s multiples were fitted on. This is the separation the board keeps — a live token is a fact, a pre-token value is a claim, and the two are never mixed in one rank.

Implied values are this radar’s own claims, derived only from the snapshot’s figures — TVL, seven-day growth, category and time running tokenless. They are not predictions that a token will be issued, and no farm plan here is a promise of one: a protocol may never launch, and a position can lose its capital to the protocol, the chain or the market.
